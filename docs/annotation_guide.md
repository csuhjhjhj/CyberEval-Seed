# CyberEval 标注与质量控制规范

## 标注目标

每条样本必须能够回答三个问题：

1. 测什么安全知识点。
2. 测哪个认知层级。
3. 如何判定模型回答正确或部分正确。

## 认知层级

| 层级 | 名称 | 说明 | 典型题型 |
| --- | --- | --- | --- |
| C1 | 知识记忆 | 概念、术语、标准事实 | 选择题 |
| C2 | 理解应用 | 参数、流程、场景匹配 | 填空题 |
| C3 | 分析推理 | 攻击链抽象分析、防御设计、漏洞影响评估 | 简答题 |
| C4 | 动态交互 | 多轮分析、代码审计、告警研判和防御决策 | 动态任务 |

## 难度等级

- L1：基础概念，主流模型应具备较高正确率。
- L2：组合知识，需要理解上下文或流程关系。
- L3：复杂推理，需要多步分析、依据组织或防御决策。

## 质量控制

1. 规则校验：检查字段完整性、题型和评分规则是否匹配。
2. 人工复核：至少一名安全背景人员复核答案和解析。
3. 模型预测试：使用多个模型测试样本区分度，剔除过易、过难或歧义样本。
4. 专家仲裁：对争议样本进行修改、降级或剔除。

## 合格样本标准

- 题干清晰，无歧义。
- 答案唯一或评分规则能处理合理变体。
- 来源可追溯。
- 不包含真实攻击载荷、企业内部敏感信息或可直接复现高危利用步骤。
