# CyberEval-Seed 预研项目计划

## 研究问题

现有网络安全大模型评测集通常存在专业覆盖不足、样本规模有限和题型单一的问题。CyberEval-Seed 用一个小规模可复现实验回答三个问题：SEU 结构能否同时承载多题型测评数据；六类安全知识领域能否形成可扩展覆盖矩阵；轻量脚本能否输出可检查的覆盖统计和模型对比结果。

## 技术路线

1. 从 CVE/CWE/CVSS、MITRE ATT&CK、OWASP Top 10、等保2.0等公开来源抽取可评测知识点。
2. 将知识点转换为 SEU 五元组，补齐标准答案、解析、评分规则、领域、难度、认知层级和敏感等级。
3. 对选择题和填空题采用自动评分；对简答题和动态场景采用规则评分加人工复核。
4. 使用覆盖矩阵检查领域、题型、难度和认知层级是否均衡。

## 阶段产出

- SEU schema V0.1。
- 预研种子样例和覆盖矩阵。
- 轻量评测脚本。
- 项目展示与后续扩展说明。
