# 敏感内容分级与安全边界

CyberEval-Seed 面向网络安全大模型评测，但所有样例均采用防御性、脱敏化和可控原则。

## L0-L4 分级

| 等级 | 说明 | 处理策略 |
| --- | --- | --- |
| L0 | 无敏感信息 | 可直接保留 |
| L1 | 公开安全知识 | 可直接保留并标注来源 |
| L2 | 抽象风险描述 | 保留防御性描述，移除可复现细节 |
| L3 | 高危漏洞细节 | 仅保留抽象类型、影响和修复建议 |
| L4 | 企业内部或攻击载荷 | 不进入公开测评集 |

## 禁止内容

- 真实可用攻击载荷。
- 未公开漏洞利用细节。
- 企业内部系统架构、账号、密钥、日志原文。
- 可直接指导入侵、持久化或绕过防护的步骤。

## 推荐写法

- 使用脱敏告警序列代替真实日志。
- 使用抽象漏洞类型代替具体可复现 payload。
- 强调风险识别、影响评估、修复建议和防御决策。
