# 内容边界与脱敏策略

CyberEval-Seed 面向网络安全大模型评测，样例设计坚持防御性、脱敏化和可控原则。这里的重点不是设置固定安全等级，而是明确哪些内容适合进入公开测评样本，哪些内容只保留抽象描述，哪些内容不进入公开数据集。

## 纳入原则

| 内容类型 | 处理策略 |
| --- | --- |
| 公开标准、公开术语、基础概念 | 可直接保留，并标注来源依据 |
| 防御性风险识别和处置建议 | 可保留，强调影响分析、检测思路和修复措施 |
| 抽象化漏洞场景 | 可保留，但去除可直接复现的攻击步骤和载荷 |
| 未公开漏洞细节、真实攻击载荷、内部系统信息 | 不进入公开测评样本 |

## 禁止内容

- 真实可用攻击载荷。
- 未公开漏洞利用细节。
- 企业内部系统架构、账号、密钥、日志原文。
- 可直接指导入侵、持久化或绕过防护的步骤。

## 推荐写法

- 使用脱敏告警序列代替真实日志。
- 使用抽象漏洞类型代替具体可复现 payload。
- 强调风险识别、影响评估、修复建议和防御决策。
- 在动态任务中使用隔离沙箱和合成数据，避免真实资产、真实账号、真实业务日志进入评测流程。
